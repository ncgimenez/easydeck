# easydeck 🪄

Une application web simple pour générer automatiquement deux versions d'une présentation (une version synthétique/adaptée et une version détaillée) avec un arrière-plan personnalisé, prête à être exportée en PowerPoint (`.pptx`).

## 🚀 Installation & Lancement

1. Cloner ou télécharger le dépôt.
2. Installer les dépendances :
   ```bash
   pip install -r requirements.txt
